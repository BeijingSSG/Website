# SuperSonicCenter

Standalone copy of [SuperSonicCenter](https://supersonic.base44.app/), the SuperSonic VEX Robotics tactical hub for the 2026–2027 VEX V5 game, Override.

The site includes:

- Team overview and VEX Override game intel
- An interactive strategy board for drawing plays on the field
- A drag-and-drop team roster
- Driver training drills for speed, reaction, and pressure

Roster changes and saved plays stay in the browser. The lineup starts with the SuperSonic roster.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
